# ITACE Digital 4.0

## Descripción
Propuesta académica de modernización del sitio web del ITACE Reynosa,
desarrollada como proyecto de la asignatura Desarrollo Web.

Este proyecto no es el sitio oficial de la institución.

## Tecnologías
- HTML5 semántico
- CSS3 y diseño responsivo
- JavaScript
- JSON
- Git y GitHub

## Estructura
- `index.html`: página principal.
- `css/style.css`: diseño y adaptación a diferentes pantallas.
- `js/script.js`: menú, filtros, directorio y galería.
- `datos/docentes.json`: datos autorizados del directorio.
- `img/`: fotografías autorizadas.
- `audio/`: grabaciones de los himnos.
- `videos/`: videos autorizados.
- `evidencias/`: capturas del desarrollo y las pruebas.

## Instalación y ejecución
1. Descarga o clona el repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta `index.html` con Live Server.
4. Comprueba que las imágenes, audios y videos estén disponibles.
5. Prueba el directorio docente y los filtros de la galería.

## Pruebas pendientes de documentar
- Navegación en computadora y celular.
- Búsqueda por nombre y materia.
- Filtro por área docente.
- Reproducción de ambos himnos.
- Funcionamiento de la galería.
- Accesibilidad, enlaces e imágenes.
- Registro de errores y correcciones.

## Créditos y permisos
La información institucional debe verificarse antes de publicarse.
Los recursos multimedia deben ser propios o contar con autorización.
Los datos del personal deben estar autorizados para su difusión.
